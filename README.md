## 🗂️ Sobre este portafolio

### ¿Por qué GitHub?

Elegí GitHub como repositorio principal para mi portafolio por:

- **Estándar de la industria**: es la plataforma más utilizada y reconocida por reclutadores y equipos técnicos de Ciencia de Datos.
- **Control de versiones con Git**: documenta la evolución de cada proyecto (commits, historial), mostrando método de trabajo y no solo el resultado final.
- **Renderizado nativo de Jupyter Notebooks**: GitHub visualiza directamente archivos `.ipynb` con código, gráficos y análisis, sin herramientas adicionales.
- **Hosting gratuito de sitios estáticos** (GitHub Pages) para complementar el repositorio con una web de presentación.
- **Documentación vía Markdown**: los `README.md` permiten estructurar cada proyecto con introducción, metodología, resultados y conclusiones.
- **Visibilidad de actividad**: el gráfico de contribuciones evidencia consistencia y compromiso con el aprendizaje continuo.

### Buenas prácticas que aplico en este portafolio

- Verificar el alcance: comparar cada módulo del curso con los proyectos documentados para reflejar todas las áreas trabajadas (limpieza de datos, análisis estadístico, machine learning y visualización).
- Estructurar cada proyecto de forma clara: introducción, metodología, resultados y conclusiones, con capturas y fragmentos de código relevantes.
- Depurar el código antes de publicarlo: revisar errores, acceso a los datos y rendimiento de los análisis.
- Redactar con lenguaje claro y profesional, apoyándome en Markdown para un formato uniforme.
- Solicitar retroalimentación externa (docentes, compañeros, profesionales del área) y priorizar la implementación de los comentarios más relevantes.
- Mantener consistencia de formato y verificar que todos los enlaces y archivos adjuntos estén activos.
- Incluir un resumen ejecutivo que destaque los análisis más relevantes y su impacto.
- Respaldar el trabajo en múltiples formatos (PDF, Markdown, notebooks) y mantener el repositorio actualizado como copia de seguridad accesible.

## 💼 Proyectos destacados

### [Reducción de Dimensionalidad aplicada a modelos predictivos (PCA y t-SNE)](03_Reduccion_Dimensionalidad_PCA_tSNE/prueba%20reduccion%20dimensionalidad.ipynb)
**Módulo:** Aprendizaje de Máquina No Supervisado

Proyecto que aborda la simplificación de variables académicas para detectar patrones y facilitar un futuro modelo predictivo de riesgo de deserción o rendimiento. Incluye:
- Escalamiento de variables (`StandardScaler`).
- Aplicación y comparación de dos técnicas de reducción de dimensionalidad: **PCA** y **t-SNE**.
- Interpretación de resultados mediante análisis de *loadings*.
- Comparación crítica y fundamentada entre ambas técnicas, con justificación final para el uso de PCA en un contexto de modelado predictivo.
- **Mejora aplicada respecto al material base**: el script de apoyo usaba un `perplexity` fijo (30) para t-SNE; en este desarrollo se ajustó a valores válidos para el tamaño de la muestra (`perplexity = 3` y `5`), evitando el error que arrojaría `scikit-learn` con el valor por defecto, y se amplió la interpretación de los componentes principales.
